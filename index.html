    Réduction pour association et événement

    Formules · prix normal

    SumUp

    Dans l'app SumUp : « Liens de paiement » → créer un lien → copier, puis collez-le ici. Le client le scanne en QR code. Chaque formule peut avoir son propre lien (montant fixe).

    Terminal SumUp Solo

    Envoie le montant directement sur le Solo et enregistre le paiement tout seul. Passe par votre relais Cloudflare, qui garde la clé SumUp secrète (voir le guide d'installation).

    Avancé : ouvrir l'app SumUp avec le montant déjà saisi

    Pour encaisser avec le lecteur de carte SumUp. Nécessite l'app SumUp Android installée sur le Chromebook. À tester sur votre appareil.

    Sauvegarde des réglages

    Vos formules, liens SumUp, réductions, thème et code sont copiés automatiquement dans le dossier des clients (fichier « htv-flash-reglages.json », sur Google Drive si le dossier y est). Après une réinstallation, choisissez de nouveau ce dossier : l'appli propose de tout remettre. Vous pouvez aussi garder une copie dans un fichier.
